# PlanetarySystemStacker (PSS)

A fork of PlanetarySystemStacker (https://github.com/Rolf-Hempel/PlanetarySystemStacker) but with a modernized Python project structure.
Also the git history has been cleaned as big files slowed down the clone process significantly.

The project can be run with `uvx` without any additional effort like this:

```bash
uvx --from git+https://github.com/derchr/PlanetarySystemStacker PlanetarySystemStacker
```
